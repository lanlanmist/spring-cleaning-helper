# 欢迎使用 大扫除小助手 V3.4

针对安卓手机答题 APP 的自动刷题工具：PaddleOCR 识别题目与选项 → 自动发送给外部 AI → OCR 读取 AI 回答 → adb 模拟点击选项 → 自动提交并流转下一题，全程无需手动操作。

## 环境搭建

- **Python**: 建议新建立一个 Python 3.9 虚拟环境搭建
```cmd
pip install -r requirements.txt
```
requirements.txt 是直接依赖（固定版本），requirements-full.txt 是全量环境快照（精确复现用）。
注意使用 CPU 版本的 paddle。首次运行 PaddleOCR 会自动下载识别模型。
- **驱动**: adb (`1.0.41`) 与 scrcpy (`scrcpy-win64-v5.0.1`) 已内置在 `adb/` 目录，无需额外下载；如需升级或更换版本，替换 `adb/` 下的 `adb.exe`、`scrcpy.exe` 及配套 dll 即可（`scrcpy-server` 需与 scrcpy 版本一致）。
- **手机端**: 打开开发者模式与 USB 调试，如有"安全设置（允许模拟点击）"选项，一并打开。建议开启勿扰模式，防止微信等 APP 通知弹窗干扰识别。

## 快速开始

```cmd
python main.py
```

1. **STEP 1 连接设备**: 手机 USB 连接电脑后，点击刷新设备列表 → 选择设备 → 连接。连接前可在设备面板勾选附加设置（禁用锁屏、关闭手机屏幕、最低亮度、高帧率 60fps、高码率 16M、720p 分辨率），连接时按勾选项执行并启动 scrcpy 镜像；默认关闭手机物理屏、USB 期间不自动锁屏。
2. **STEP 2 标定**: 点「一键顺序标定」，依次框选外部 AI 的回答区、点选 AI 输入框、点选 AI 发送键。标定结果只保存在内存中，关闭程序后需重新标定；Prompt 与延时参数会自动保存。
3. **页面布局**: 请打开外部 AI 网页（千问-Qwen3-Flash 回答速度较快，推荐使用）与本程序窗口，均放置在前页，运行期间不要遮挡。
4. **启动**: 点击【启动全自动任务】。答题数量上限（默认 20）、等待 AI 作答时间等参数均可在界面调整并自动保存；勾选「保存每题判分截图」后，每题判分页会在"加载中"遮罩消失后保存到 `screenshots/<启动时间>/`。

## 停止与保护

- 随时可点【紧急停止】或按 **Esc** 紧急停止；
- 自动停止保护：连续 5 轮无法识别、预览连续 10 次截图失败（设备断开）、达到答题数量上限。

## 运行日志

每次运行都会写入 `logs/app-YYYYMMDD.log`（单文件 2MB、最多保留 5 份）。日志包含页面状态变化、识别出的题干与每个选项文本、选项点击坐标、AI 答案、作答与正确答案的对比、单题耗时，以及滚动采集/竖带槽位等排障信息。无人值守跑一整晚后出现异常，可直接查看日志定位。

程序启动时窗口先出现，OCR 模型在后台预热，日志会记录「OCR 引擎预热开始 / 预热完成（含耗时）」或预热失败原因。若在预热结束前就点了【启动全自动任务】，任务会先等待预热完成再开始识别，无需重启程序。
